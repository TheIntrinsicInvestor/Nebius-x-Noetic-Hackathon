**Goal:** A working covenant early-warning demo: a credit agreement plus financials go in; covenants with clause citations, a headroom forecast, first breach, what-ifs and an open-vs-closed benchmark come out.

## Review Focus
1. **Step-down crossed inside the forecast:** the threshold used for a date is the latest step-down on or before it, else the base threshold. Test in Task 2.
2. **Covenant extracted with a missing threshold:** the engine skips it and reports it in `needs_input`; it does not crash. Test in Task 3.
3. **Zero or negative EBITDA:** leverage is `inf` (a max covenant is breached). Zero interest gives interest cover `inf` (a min covenant passes). Test in Task 2.
4. **Fewer than 4 quarters of history:** `project` raises `ValueError("need >= 4 quarters")`; the API returns 422. Test in Task 3.
5. **Narrative contains a number not in engine output:** `validate_numbers` returns the offending tokens and the insight is dropped. Test in Task 6.

### Task 3: Forecast, headroom analysis, reverse stress, refi (13:30-14:00)

**Files:** Create `api/engine/forecast.py`, `api/engine/headroom.py`, `api/engine/refi.py`; Test `tests/test_forecast.py`, `tests/test_headroom.py`

**Interfaces:**
- Consumes: Task 2 functions, `Scenario`, `CovenantSet`.
- Produces:
  - `project(history: list[Quarter], n: int = 6, sc: Scenario = Scenario()) -> list[Quarter]`. Rules: revenue = same quarter last year × (1 + mean YoY growth of the last 4 quarters, clamped to ±30%) × (1 + revenue_pct). EBITDA margin = trailing-4Q EBITDA/revenue × (1 + ebitda_pct); stored as `ebit = margin·rev − da`, `addbacks = 0`. da/capex = trailing-4Q mean, + `capex_extra/4` in the first 4 forecast quarters. DSO = trailing-4Q mean `receivables / revenue × 91.25` + dso_delta; DIO and DPO the same on cogs (cogs ratio trailing). Rate = trailing-4Q interest / mean debt + rate_bp/1e4/4 per quarter. Cash = prev cash + EBITDA − interest − capex − ΔNWC − principal (principal = trailing mean). If cash < 0, then debt += −cash and cash = 0 (revolver draw). Raise `ValueError("need >= 4 quarters")` if `len(history) < 4`.
  - `CovenantPoint(period_end: date, kind: str, value: float, threshold: float, headroom_pct: float, is_forecast: bool, breached: bool)` (pydantic)
  - `Analysis(points: list[CovenantPoint], first_breach: CovenantPoint | None, binding_kind: str | None, needs_input: list[str], reverse_stress: dict[str, float], refi: dict, forecast: list[Quarter])` (pydantic)
  - `analyze(history: list[Quarter], cs: CovenantSet, sc: Scenario = Scenario(), n: int = 6, as_of: date | None = None) -> Analysis`. Evaluates every covenant with a non-null threshold at each quarter from index 3 onward (history + forecast). `first_breach` = earliest breached forecast point. `binding_kind` = the covenant with the lowest min headroom over the forecast. `reverse_stress = {"ebitda_fall_pct": x, "dso_days": y}`: bisection on `ebitda_pct` in [−0.9, 0] and `dso_delta` in [0, 180] for the largest shock with no forecast breach (tolerance 0.005 / 0.5 days); `0` if the base case already breaches.
  - `refi_summary(fac: Facility, as_of: date, debt: float) -> dict` with keys `months_to_maturity`, `start_talks_by` (maturity − 12 months), `est_breach_cost` (= 0.0025·debt fee + 0.01·debt one-year margin step; labelled as an assumption based on the Nortech waiver).
